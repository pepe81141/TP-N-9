# Sistema de Gestion de Gimnasio

Aplicacion desarrollada en Python que implementa un sistema CRUD completo para la gestion de clientes, instructores y membresias. 

Se conecta de forma remota a una base de datos MySQL alojada en la nube a traves de Clever Cloud, utilizando variables de entorno para proteger los datos sensibles.

## Requisitos de instalacion

1. Clonar este repositorio en tu computadora.
2. Instalar las dependencias ejecutando: pip install -r requirements.txt
3. Crear un archivo llamado .env basado en la plantilla .env.example con tus datos reales.
4. Ejecutar la aplicacion con: python index.py
